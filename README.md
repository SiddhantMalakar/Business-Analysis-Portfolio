# 🚀 About This Repository

Welcome to my Business Analysis learning portfolio!

This repository documents my journey toward becoming a Business Analyst by learning industry-standard methodologies, creating professional documentation, modeling business processes, and solving real-world business problems.

The focus is on practical learning through case studies, project documentation, Agile practices, and business process analysis.

# 🎯 Learning Goals

- Understand the complete Software Development Life Cycle (SDLC)
- Master Agile and Scrum methodologies
- Learn Business Requirement Gathering
- Write professional BRD, FRD and SRS documents
- Create User Stories & Acceptance Criteria
- Build UML & BPMN diagrams
- Learn Jira & Confluence
- Build a Business Analyst Portfolio
- Prepare for BA interviews
